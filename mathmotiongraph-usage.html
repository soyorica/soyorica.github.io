MathMotionGraph の使い方

直交座標・媒介変数・極座標のグラフと、不等式の領域を描画するジェネレーターです。

基本的な使い方

  1. インストール に従って MathMotionGraph をインストールします。
  2. エディットページの「エフェクト」→「ジェネレーター」から MathMotionGraph をタイムラインに配置します。
  3. インスペクタでグラフの種類を Cartesian にし、数式欄に y = sin(x) などの数式を入力します。
  4. View で表示範囲、Boundary / Region で線と領域の見た目を調整します。
  5. Axes / Grid で座標軸とグリッドを調整します。
  6. Fusion で使う場合は、Shift + Space で追加して出力を MediaOut に接続します。映像に重ねる場合は Merge で合成します。

描画モードと入力例

モード 入力例 用途
Cartesian y = sin(x) 関数のグラフ
Cartesian x^2 + y^2 <= 4 不等式の領域
Cartesian x^2 + y^2 <= 9 AND y >= abs(x) 複数の条件による領域
Parametric X に cos(t)、Y に sin(t) 媒介変数による曲線。t の範囲も指定
Parametric X に s*sqrt(1-(t^2)/2)、Y に t*sqrt(1-(s^2)/2) 媒介変数による領域。s, t の範囲も指定
Polar 1 + cos(theta) 極座標の曲線。theta の範囲も指定

アニメーションを作る

  • 線を徐々に描く：開始フレームで Draw End を 0、終了フレームで 1 にしてキーフレームを設定します。Draw Start は 0 にします。
  • グラフを変形する：y = a*sin(x) のように定数を使い、a にキーフレームを設定します。
  • 点を動かす：Moving Point を有効にし、点の位置である Point Position にキーフレームを設定します。
  • 領域を出現させる：Region Animation から Wipe / Trace then Fill / Trace and Fill を選びます。

主な設定

設定 内容
Graph Type / Formula 描画モードと数式
Add Second Curve / Fill Between 2本目の曲線と、曲線間の塗りつぶし
Constants a, b, c, d 数式で使用する調整可能な定数
Moving Point / Guide Values 移動点・補助線・座標値の表示
Boundary / Region 線と塗りつぶしの色・透明度
View / Keep Equal Scale 表示範囲と縦横の単位の比率
Axes / Grid / Background 軸・目盛り・グリッド・背景
Curve Samples / Region Resolution 曲線の滑らかさと領域の描画解像度

利用できる数式

  • 変数：x, y, s, t, theta（使用する描画モードに応じて指定）。
  • 定数：a, b, c, d, pi, e。
  • 演算子：+, -, *, /, ^。掛け算は 2*x のように * を明示します。
  • 関数：sin, cos, tan, asin, acos, atan, sqrt, abs, exp, log, ln, floor, ceil, min, max。
  • 標準の数値フォントは New Computer Modern Math です。別のインストール済みフォントに変更することもできます。
