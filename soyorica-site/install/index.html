インストール方法

DaVinci Resolveを終了してからファイルを配置し、Resolveを再起動します。パスはそのままコピーできます。

1. DaVinci Resolveを終了する

ファイルをコピーする前にResolveを終了し、配布ZIPを展開してください。

2. Fuseを配置する

Windows（ユーザー単位・推奨）

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Windows（PCの全ユーザー）

%PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Fusion\Fuses

macOS

~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Fuses

Linux

~/.local/share/DaVinciResolve/Fusion/Fuses

3. MathMotionGraphは.settingも配置する

MathMotionGraph / MathMotionGraph_Liteは、.fuseが描画本体、.settingがEditページ用ジェネレーターです。.settingだけでは動きません。

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Generators
製品版とLite版は別登録名なので両方インストールできます。同じ登録名の古い.fuseを別の検索先へ重複配置しないでください。

4. Resolveを再起動して確認する

HairSway

Fusionページの「ツールを追加」から Fuses > Warp > HairSway を追加します。

MathMotionGraph / Lite

EditではEffects → Generatorsから、FusionではShift + SpaceからMathMotionGraphまたはMathMotionGraph_Liteを検索します。
