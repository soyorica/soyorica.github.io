MathText Usage

A generator for displaying equations using LaTeX-style notation. It does not implement all LaTeX features.

Basic usage

  1. Follow the installation. MathText has embedded fonts.
  2. On the Edit page, drag MathText from Effects → Titles onto a track above your footage.
  3. Enter an expression in the Inspector's Formula field, for example \frac{1}{2}.
  4. Adjust Size, then use Position X / Position Y to place the equation.
  5. Set the main color with Base Color under Appearance.
  6. Use WriteProgress under Write Animation to add an entrance animation.
  7. In Fusion, add MathText using Shift + Space. Connect it to MediaOut for standalone output, or to Merge to composite it over footage.

Formula examples

Expression Enter in Formula
Superscript and subscript x^2 + a_1
Fraction \frac{a+b}{c}
Square root \sqrt{x}
Integral \int_a^b f(x)\,dx
Greek letters \alpha + \beta
Color specific characters y = a {\color{1}x} + b
  • Enter the expression directly, without enclosing it in $ characters.
  • Group multiple characters with braces, for example x^{a+b}.
  • To change the color of specific characters, use \color{}. Inside the braces, enter a color name such as red, or a number from 1 to 4 for a color set in the Inspector.
  • If an expression does not appear, check matching braces and command spelling, then try a shorter expression. Also check the error message displayed on screen.

Animation settings

Setting Purpose
Write Progress of the entrance animation
Erase Progress of the exit animation
Charactor Lag How much the animation start times of individual characters overlap
Outline width Line width during the animation; does not affect the line width of the characters displayed after the animation ends
