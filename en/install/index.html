Install

Installation

Choose your OS, copy the files to the shown locations, then restart Resolve.

01

Quit DaVinci Resolve

Extract the distributed ZIP and copy the files while Resolve is closed.

02

Copy the Fuse

Choose your operating system.

Current user (recommended)

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

All users

%PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Fusion\Fuses
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Fuses
~/.local/share/DaVinciResolve/Fusion/Fuses
03

MathMotionGraph: .setting

For MathMotionGraph / Lite, .fuse contains the renderer and .setting provides the Edit-page Generator. The .setting does not work alone. On Windows, place it here:

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Generators
04

Restart Resolve and verify

HairSway
On Fusion, use Add Tool and choose Fuses > Warp > HairSway.

MathMotionGraph / Lite
On Edit, look under Effects → Generators; on Fusion, press Shift + Space and search for the product name.
