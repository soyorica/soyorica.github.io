Installation

Close DaVinci Resolve, copy the files to the correct folders, and restart Resolve. The paths below are ready to copy.

1. Close DaVinci Resolve

Quit Resolve before copying files, then extract the distributed ZIP.

2. Copy the Fuse

Windows — current user (recommended)

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Windows — all users

%PROGRAMDATA%\Blackmagic Design\DaVinci Resolve\Fusion\Fuses

macOS

~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Fuses

Linux

~/.local/share/DaVinciResolve/Fusion/Fuses

3. MathMotionGraph also needs its .setting file

For MathMotionGraph / MathMotionGraph_Lite, the .fuse contains the renderer and the .setting provides the Edit-page generator. The .setting file does not work by itself.

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Generators
Full and Lite use separate registered names, so both can be installed. Avoid duplicate copies of an older .fuse under the same registered name.

4. Restart Resolve and verify

HairSway

On the Fusion page, use Add Tool and choose Fuses > Warp > HairSway.

MathMotionGraph / Lite

On Edit, look under Effects → Generators. On Fusion, press Shift + Space and search for MathMotionGraph or MathMotionGraph_Lite.
