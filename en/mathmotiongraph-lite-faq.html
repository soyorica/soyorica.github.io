MathMotionGraph Lite FAQ

Installation questions

I cannot run install.bat.

  • There are several possible causes, so we cannot provide one guaranteed solution.
  • In this case, follow the manual installation steps.

The plugin does not appear after installation.

  • Extract the entire ZIP and run install.bat from the extracted folder.
  • Restart DaVinci Resolve.
  • In Fusion, press Shift + Space and search for MathMotionGraph_Lite.
  • If it is still missing, check that the files are in the folders listed in manual installation.
  • On the Edit page, check Generators for MathMotionGraph_Lite.

It says Installation complete., but the plugin does not work.

  • Keep install.bat with the supplied files; do not move it to another folder on its own.
  • Check for MathMotionGraph_Lite.fuse in the folder below. If it is missing, copy it using manual installation.
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses
  • If the Fusion node is available but the Edit template is missing, check MathMotionGraph_Lite.setting and MathMotionGraph_Lite.png in the Edit destination.

Can I run install.bat on Mac / Linux?

  • install.bat is for Windows. These paths and installation steps are also for Windows.
  • Use manual installation as a reference to copy files to the corresponding folders. Correct operation outside Windows is not guaranteed.

How do I update or uninstall the plugin?

  • Before updating, back up projects in use and the previous version’s files.
  • To update, close DaVinci Resolve, extract the new ZIP, and run install.bat. Files with the same names will be overwritten.
  • To uninstall, close DaVinci Resolve and run the supplied uninstall.bat.
  • If uninstall.bat does not work, remove only MathMotionGraph_Lite.fuse, MathMotionGraph_Lite.setting, and MathMotionGraph_Lite.png from the folders listed in manual installation.
  • Do not remove other plugins’ files or the entire Fusion folder.
  • Projects using the removed plugin may no longer render as before.

Product questions

Numbers or tick labels are missing.

  • Install the .otf files in the supplied Fonts folder and restart DaVinci Resolve. install.bat does not install fonts automatically.
  • Select New Computer Modern Math or another installed font for the number labels in the Inspector.
  • Check that axis labels or Guide Values are enabled.

My graph is not visible.

  • Start with a simple expression such as y = sin(x).
  • Write multiplication explicitly, as in 2*x, and check matching parentheses.
  • Check the X / Y minimum and maximum values to make sure the graph lies within the visible range.
  • In the full version, choose the graph mode that matches your expression.
  • Lite does not support parametric or polar modes, or combined AND / OR conditions.

How does Lite differ from the full version?

  • Lite includes Cartesian graphs, single inequalities, moving points, axes, and grids.
  • The full version also includes advanced animations, parametric and polar modes, a second curve, fill between curves, and combined conditions.
  • See the comparison with the full version.

Graph rendering is slow.

  • Try lowering Region Resolution under advanced.
  • Lower values reduce processing load but also change the smoothness of curves and regions. Check the result before export.
  • Try lowering the playback resolution or using caching.
