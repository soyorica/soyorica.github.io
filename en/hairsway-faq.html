HairSway FAQ

Installation questions

I cannot run install.bat.

  • There are several possible causes, so we cannot provide one guaranteed solution.
  • In this case, follow the manual installation steps.

The plugin does not appear after installation.

  • Extract the entire ZIP and run install.bat from the extracted folder.
  • Restart DaVinci Resolve.
  • In Fusion, press Shift + Space and search for HairSway.
  • If it is still missing, check that the files are in the folders listed in manual installation.

It says Installation complete., but the plugin does not work.

  • Keep install.bat with the supplied files; do not move it to another folder on its own.
  • Check for HairSway.fuse in the folder below. If it is missing, copy it using manual installation.
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Can I run install.bat on Mac / Linux?

  • install.bat is for Windows. These paths and installation steps are also for Windows.
  • Use manual installation as a reference to copy files to the corresponding folders. Correct operation outside Windows is not guaranteed.

How do I update or uninstall the plugin?

  • Before updating, back up projects in use and the previous version’s files.
  • To update, close DaVinci Resolve, extract the new ZIP, and run install.bat. Files with the same names will be overwritten.
  • To uninstall, close DaVinci Resolve and run the supplied uninstall.bat.
  • If uninstall.bat does not work, remove only HairSway.fuse from the folders listed in manual installation.
  • Do not remove other plugins’ files or the entire Fusion folder.
  • Projects using the removed plugin may no longer render as before.

Product questions

Nothing moves after I add the effect.

  • Check the node connections: the node for the image you want to animate → HairSway → MediaOut.
  • Check the overall Enable control and the group's Enable Sway control. Only Sway 1 is enabled by default.
  • Place the pins on the area you want to move, and check that the sway amount and Mix are not zero.
  • Play the timeline to see the motion.

The face or background moves too.

  • Reduce Influence Radius to cover only the required area.
  • Place Anchor pins in the Protection tab on areas that should remain still.
  • Use Root Lock / Root Protection to protect the root area.

Performance is slow.

  • Disable Enable Sway for unused groups.
  • Limit each group's Influence Radius to the required area.
  • Try lowering the playback resolution or using caching.
