MathMotionGraph Lite — Installation

Windows installation instructions.

Install with install.bat

  1. Close DaVinci Resolve.
  2. Right-click the downloaded MathMotionGraph_Lite.zip and select “Extract All”.
  3. Double-click install.bat in the extracted folder.
  4. When Installation complete. appears, press a key to close the window.
  5. Open the .otf files in the extracted folder’s Fonts folder and choose “Install”.
  6. Start DaVinci Resolve.

Find the plugin

  • In Fusion, press Shift + Space and search for MathMotionGraph_Lite. If you can add the MathMotionGraph_Lite node, the Fuse is installed correctly.
  • On the Edit page, open Effects → Generators and check that MathMotionGraph_Lite is available.
  • For usage instructions, see MathMotionGraph Lite usage.

Manual installation

If the plugin does not appear after running install.bat, close DaVinci Resolve and copy the files below. Paste each destination into the File Explorer address bar. Create missing folders. The Installation complete. message alone may not confirm that the files were copied successfully.

Fuse

Copy MathMotionGraph_Lite.fuse from the extracted MathMotionGraph_Lite folder’s Fuses folder to the destination below.

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Edit

Copy MathMotionGraph_Lite.setting and MathMotionGraph_Lite.png from the extracted MathMotionGraph_Lite folder’s Edit folder to the destination below.

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Generators

After copying, restart DaVinci Resolve and check the plugin.
