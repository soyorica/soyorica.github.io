MathMotionGraph Lite Usage

The Lite edition supports Cartesian graphs and regions defined by a single inequality. See MathMotionGraph usage for the full version.

Basic usage

  1. Follow installation to install MathMotionGraph Lite.
  2. On the Edit page, drag MathMotionGraph_Lite from Effects → Generators onto the timeline.
  3. In the Inspector, enter a formula such as y = sin(x) or x^2 + y^2 <= 4 in Formula.
  4. Set the visible range under View, and adjust the line and region appearance under Boundary / Region.
  5. Adjust the axes and grid under Axes / Grid.
  6. In Fusion, add the node using Shift + Space and connect its output to MediaOut. Use a Merge node to place the graph over footage.

Animate a graph

  • Change the graph shape: use a constant in a formula such as y = a*sin(x), then keyframe a.
  • Move a point: enable Moving Point and keyframe Point Position.

  • Lite supports the variables x and y. See the MathMotionGraph expression list for constants, operators, and functions.
  • Lite supports animations that change the graph shape or move a point. Drawing lines progressively and revealing regions are available only in the full version.
  • Use Vertical / Horizontal Guide for guide lines and Guide Values for coordinate labels.
