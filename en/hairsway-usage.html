HairSway Usage

Add natural sway to hair, fabric, or cords using pins. Use up to eight groups with two to six pins per group.

Basic usage

  1. Follow installation to install HairSway.
  2. Create a Fusion clip and open the Fusion page.
  3. Import the image you want to animate. Keep the moving parts and the other parts on separate nodes.
  4. Search for HairSway with Shift + Space, then connect the node for the moving part → HairSway → MediaOut.
  5. Display HairSway in the viewer and select it. Place the Sway 1 pins from the root toward the tip.
  6. Adjust Sway Distance and Speed, then play the timeline to preview the motion.
  7. For another section of hair, enable Enable Sway in Sway 2 or a later group and place its pins.

Motion settings

Setting Purpose
Enable / Mix Enable the effect and set its overall strength
Master Amount / Speed Scale the amount and speed across all groups
Frame Rate / Start Frame Reference frame rate and start frame
Pin Count / Root Pin / Tip Pin Pin count and root/tip positions
Sway Distance Motion amplitude
Influence Radius / Edge Feather Deformation area and edge softness
Speed / Phase / Lag Speed, phase, and delay toward the tip
Root Lock / Root Protection Root locking and protection

Protect the face or background

  • Use Anchor 1–4 in the Protection tab to protect areas such as the face or background.
  • If the root moves too much, adjust Root Lock / Root Protection.
  • For better performance, disable unused groups and keep Influence Radius limited to the required area.
