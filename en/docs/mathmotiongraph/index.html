MathMotionGraph

How to use MathMotionGraph / Lite, write expressions, and understand the Inspector controls.

Overview and Lite differences

MathMotionGraph is a DaVinci Resolve / Fusion generator that draws graphs from mathematical expressions. Its transparent background makes it suitable for educational and explanatory video overlays.

The Lite edition supports one Cartesian function, one implicit equation, one inequality with fill, Moving Point, guides, value labels, and keyframable constants a–d. The full edition adds AND / OR regions, chained inequalities, a second function, Parametric, Polar, Draw Start / End, Region Animation, and path controls.

Lite has no watermark, time limit, or product-imposed resolution limit.

Create your first graph

Edit page

  1. Drag MathMotionGraph or MathMotionGraph_Lite from Effects → Generators to the timeline.
  2. Select the clip and change Formula to an expression such as y = sin(x).
  3. For transparent overlay, place the graph clip on a video track above your footage.

Fusion page

Press Shift + Space, search for the registered tool name, and connect Output to MediaOut. To overlay on footage, connect the graph to a Merge Foreground.

Formula syntax

Use ASCII letters and operators. Write multiplication explicitly, such as 2*x or a*sin(b*x). Operators are + - * / ^ and angles are in radians. Constants include pi and e; adjustable parameters are a, b, c, and d.

Supported functions: sin, cos, tan, asin, acos, atan, sqrt, abs, exp, log, ln, floor, ceil, min, max.

Cartesian

Examples include y = sin(x), x^2+y^2 = 4, and x^2+y^2 <= 4. Equations draw boundaries; inequalities can fill regions.

Multiple conditions (Full)

Use conditions such as x^2+y^2 < 4 AND x^2+y^2 >= 1. Lite accepts only one comparison.

Parametric / Polar (Full)

Parametric Curve uses x(t) and y(t); Parametric Region uses expressions in t and s. Polar uses r(theta).

Animation and Moving Point

In the full edition, Draw Start / Draw End controls the visible portion of a curve. Cartesian implicit equations and inequalities can use Wipe, Trace then Fill, or Trace and Fill.

Moving Point is available in both editions. Keyframe Point Position from 0 to 1 to move along the curve or boundary. Constants a–d can also be keyframed.

Troubleshooting

The tool is not listed

Close Resolve before copying files, confirm the ZIP was extracted, verify the extensions and destination folders, then restart Resolve. Check the Generators path for Edit and the registered tool name for Fusion.

The node exists but nothing is drawn

The Edit macro also requires the matching Fuse. Do not mix a full .setting with a Lite .fuse. Also confirm that the expression has geometry inside the current view range.

Error or empty region

Missing operator usually means an omitted *, Unknown name indicates an invalid function/variable or full-width character, and Min/Max errors indicate an invalid range. Lite rejects multiple conditions/chained inequalities. For Parametric Region, keep t Samples × s Samples at or below 32,768.

Slow or missing lines

Edit at standard quality first. Increase Curve Samples or Region Resolution only where needed. Because the renderer samples the graph, discontinuities or very fine shapes may be missed.
