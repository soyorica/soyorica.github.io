MathMotionGraph Usage

A generator for Cartesian, parametric, and polar graphs, as well as inequality regions.

Basic usage

  1. Follow installation to install MathMotionGraph.
  2. On the Edit page, drag MathMotionGraph from Effects → Generators onto the timeline.
  3. In the Inspector, select Cartesian as the graph type and enter a formula such as y = sin(x) in the formula field.
  4. Set the visible range under View, and adjust the line and region appearance under Boundary / Region.
  5. Adjust the axes and grid under Axes / Grid.
  6. In Fusion, add the node using Shift + Space and connect its output to MediaOut. Use a Merge node to place the graph over footage.

Graph modes and examples

Mode Input Use
Cartesian y = sin(x) Function graph
Cartesian x^2 + y^2 <= 4 Inequality region
Cartesian x^2 + y^2 <= 9 AND y >= abs(x) Region defined by multiple conditions
Parametric X: cos(t), Y: sin(t) Parametric curve; also set the t range
Parametric X: s*sqrt(1-(t^2)/2), Y: t*sqrt(1-(s^2)/2) Parametric region; also set the s and t ranges
Polar 1 + cos(theta) Polar curve; also set the theta range

Animate a graph

  • Draw a line progressively: keyframe Draw End from 0 at the start to 1 at the end. Keep Draw Start at 0.
  • Change the graph shape: use a constant in a formula such as y = a*sin(x), then keyframe a.
  • Move a point: enable Moving Point and keyframe Point Position.
  • Reveal a region: choose Wipe, Trace then Fill, or Trace and Fill under Region Animation.

Main settings

Setting Purpose
Graph Type / Formula Graph mode and formula
Add Second Curve / Fill Between Second curve and fill between curves
Constants a, b, c, d Adjustable constants used in formulas
Moving Point / Guide Values Moving point, guides, and coordinate labels
Boundary / Region Line and fill colors and opacity
View / Keep Equal Scale Visible range and equal axis scaling
Axes / Grid / Background Axes, ticks, grid, and background
Curve Samples / Region Resolution Curve smoothness and region resolution

Supported expressions

  • Variables: x, y, s, t, theta, depending on the graph mode.
  • Constants: a, b, c, d, pi, e.
  • Operators: +, -, *, /, ^. Write multiplication explicitly, as in 2*x.
  • Functions: sin, cos, tan, asin, acos, atan, sqrt, abs, exp, log, ln, floor, ceil, min, max.
  • The default number font is New Computer Modern Math. You can also select another installed font.
