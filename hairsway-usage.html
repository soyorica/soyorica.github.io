インストール 使い方 FAQ

HairSway の使い方

髪・衣服・紐などにピンを配置して、自然な揺れを加えるエフェクトです。最大8グループ、各グループ2〜6個のピンを使えます。

基本的な使い方

  1. インストール に従って HairSwayをインストールします。
  2. Fusionクリップを作成し、Fusionページへ移動します。
  3. 動かしたい画像を取り込みます。この際、動かしたい部分とそれ以外の部分で別のノードとなるようにしてください。
  4. Shift + Space で HairSway を検索し、動かしたい部分のノード → HairSway → MediaOut の順につなぎます。
  5. HairSway をビューアに表示して選択し、Sway 1 のピンを根元から毛先に向けて配置します。
  6. Sway Distance と Speed を調整し、タイムラインを再生して揺れを確認します。
  7. 別の毛束も揺らす場合は、Sway2以降の Enable Sway を有効にしてピンを配置します。

揺れの設定

設定 内容
Enable / Mix エフェクト全体の有効・無効と適用率
Master Amount / Speed 全グループの揺れ幅・速度を一括調整
Frame Rate / Start Frame 動きの基準フレームレートと開始フレーム
Pin Count / Root Pin / Tip Pin ピンの数と根元・毛先の配置
Sway Distance 揺れの振り幅
Influence Radius / Edge Feather 変形の影響範囲と境界のぼかし
Speed / Phase / Lag 速度・位相・先端へ向かう遅れ
Root Lock / Root Protection 根元付近の固定・保護

顔や背景を保護する

  • Protection タブの Anchor 1〜4 を使い、動かしたくない顔や背景などを保護します。
  • 根元が動きすぎる場合は Root Lock / Root Protection を調整します。
  • 動作が重い場合は、不要なグループを無効にし、Influence Radius を必要な範囲に絞ります。
