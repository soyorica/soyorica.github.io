HairSway

HairSwayの基本操作とInspectorパラメータを、実際のDaVinci Resolve画面と対応させて確認できます。
VERSION 1.2.3

概要

HairSwayは、レイヤー分けされたイラストの髪、リボン、服の裾などを、キーフレームを使わずに自動で揺らすDaVinci Resolve / Fusion用Fuseです。Viewer上のピン列に沿って画像を局所変形し、1ノードで最大8箇所の揺れを個別に設定できます。

画像の準備

揺らしたい部分を透明背景の別レイヤーに分けて使用する方法を推奨します。前髪、横髪、後ろ髪、リボン、服の裾などを必要に応じて分離してください。分離されていない画像では、Polygonなどで対象を切り抜いてからHairSwayへ接続します。

基本操作

  1. 揺らしたいレイヤーをFusionページへ読み込み、HairSwayを追加してInputへ接続します。
  2. Sway 1を開き、Enable Sway 1とShow Pins in Viewerを有効にします。
  3. Pin Countを決め、Root Pinを根元に、残りのピンを毛先へ向かって順番に置きます。
  4. Influence Radiusを対象の髪束だけに届く程度まで絞ります。
  5. 再生しながらSway Distance、Speed、Tip Lag、Roundness、Root Lock、Root Protectionを調整します。
複数の髪束を設定するときは、設定済みSwayのShow Pins in Viewerをオフにしてから次のSwayを表示すると、ピンを選びやすくなります。

Protection Pin

Protection Pinは、すべてのSwayによる変形から特定領域を保護します。頭頂部、顔、耳、髪の付け根、リボンの結び目、服の固定部分などに使えます。最大4個です。

頭頂部や顔が動く場合は、Root Pinの位置→Root Lock→Root Protection→Influence Radius→Protection Pinの順に見直すと原因を切り分けやすくなります。

トラブル対処

頭頂部や顔まで動く

  1. Root Pinを髪と頭皮の境界へ置き直す。
  2. Root Lockを0.30〜0.45程度まで上げて確認する。
  3. Root Protectionを増やす。
  4. Influence Radiusを髪束の幅に合わせて小さくする。
  5. 必要ならProtection Pinを置く。

再生が重い

Viewerのプロキシ解像度を下げ、未使用のSwayをオフにし、必要以上のSwayを使わないようにします。最終確認時にフル解像度へ戻してください。距離・半径は元解像度基準で自動調整されます。
