MathMotionGraph

MathMotionGraph / MathMotionGraph_Liteの使い方、数式ルール、Inspectorの主要パラメータをまとめています。

概要・Lite版との違い

MathMotionGraphは、数式からグラフを描くDaVinci Resolve / Fusion用ジェネレーターです。背景を透明にして教材・解説動画・プレゼンテーションなどへ重ねられます。

Lite版でも、Cartesianの1本の関数、単独の陰関数等式、単一の不等式と領域塗り、Moving Point、補助線、座標値表示、定数a〜dのキーフレームを使えます。製品版ではAND / OR、連鎖不等式、2本目の関数、Parametric、Polar、Draw Start / End、Region Animationなどが追加されます。

Lite版には透かし・時間制限・製品側の解像度制限はありません。

最初のグラフ

Editページ

  1. EffectsのGeneratorsからMathMotionGraphまたはMathMotionGraph_Liteをタイムラインへドラッグします。
  2. InspectorのFormulaをy = sin(x)などへ変更します。
  3. 透明背景で重ねる場合は、グラフを映像より上のビデオトラックへ置きます。

Fusionページ

Shift + Spaceで登録名を検索し、OutputをMediaOutへ接続します。背景映像へ重ねる場合は、グラフをMergeのForegroundへ接続します。

数式の書き方

半角英数字と演算子を使い、掛け算は2*x、a*sin(b*x)のように省略せず書きます。演算子は + - * / ^、角度はラジアンです。定数はpi・e、調整用定数はa・b・c・dです。

使用できる関数: sin, cos, tan, asin, acos, atan, sqrt, abs, exp, log, ln, floor, ceil, min, max。

Cartesian

y = sin(x)、x^2+y^2 = 4、x^2+y^2 <= 4などを入力できます。等式は境界のみ、不等式は領域を塗れます。

複数条件（製品版）

x^2+y^2 < 4 AND x^2+y^2 >= 1のようにAND / ORを使えます。Liteは1つの比較のみです。

Parametric / Polar（製品版）

ParametricのCurve (t)ではx(t)とy(t)を、Region (t, s)ではtとsを使った領域式を設定します。Polarではr(theta)を指定します。

アニメーション・Moving Point

製品版ではDraw Start / Draw Endで線の表示範囲を動かせます。Cartesianの陰関数等式・不等式ではWipe、Trace then Fill、Trace and Fillを選択できます。

Moving Pointは両版で利用でき、Point Positionを0から1へキーフレームすると曲線・境界に沿って移動します。定数a〜dもキーフレームできます。

トラブル対処

一覧に表示されない

Resolveを終了してからファイルをコピーしたか、ZIPを展開したか、拡張子と配置先を確認し、Resolveを再起動してください。Editで見つからない場合はGeneratorsの配置先を、Fusionでは登録名を確認します。

ノードはあるが描画されない

Editマクロには対応するFuseも必要です。製品版の.settingとLiteの.fuseを混在させないでください。数式が現在の表示範囲内に形状を持つかも確認します。

エラー・空領域

Missing operatorは*などの省略、Unknown nameは関数・変数名や全角文字、Min / Maxは範囲の大小、Lite制限は複数条件・連鎖不等式を確認します。Parametric Regionではt Samples × s Samplesを32,768以下にします。

遅い・線が欠ける

まず標準設定で編集し、必要な箇所だけSamplesやRegion Resolutionを上げます。サンプリングによる近似のため、不連続点や非常に細かい形状は欠ける場合があります。
