よくある質問

製品別に絞り込み、購入前・使用中のよくある確認事項を探せます。

HairSwayはDaVinci Resolve無料版で使えますか？
はい。HairSwayの資料ではDaVinci Resolve 21の無料版・Studio版に対応しています。
HairSwayでレイヤー分けされていない画像も使えますか？
使えますが、揺らしたい部分が透明背景の別レイヤーになっている画像を推奨します。分離されていない場合は、FusionのPolygonなどで対象を切り抜いてからHairSwayへ接続します。
HairSwayで顔や頭頂部まで動いてしまいます。
Root Pinの位置、Root Lock、Root Protection、Influence Radiusの順で見直し、必要ならProtection Pinを使います。
MathMotionGraphのLite版には透かしがありますか？
ありません。Lite版には透かし、時間制限、製品側の解像度制限はありません。
MathMotionGraph Liteと製品版の違いは何ですか？
LiteはCartesianの1本の関数、単独の陰関数等式、単一不等式、Moving Pointなどに対応します。製品版ではAND / OR、2本目の関数、Parametric、Polar、Draw Start / End、Region Animationなどが追加されます。
MathMotionGraphはEditページとFusionページの両方で使えますか？
はい。.settingを使うEditページのジェネレーターと、.fuseを直接追加するFusionページの両方を想定しています。Edit用.settingだけでは描画できず、対応する.fuseも必要です。
インストールしたのに製品が表示されません。
Resolveを終了してからファイルをコピーしたか、ZIPを展開したか、配置先と拡張子が正しいかを確認してResolveを再起動してください。MathMotionGraphはEdit用.settingとFuseの両方の配置も確認します。
問い合わせはどこからできますか？
BOOTHショップからお問い合わせください。製品名、OS、DaVinci Resolveのバージョン、無料版/Studio版、Fusion/Editのどちらで使っているか、再現手順、エラー内容があると確認しやすくなります。
