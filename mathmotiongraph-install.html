インストール 使い方 FAQ

MathMotionGraph のインストール

Windows 向けのインストール手順です。

install.bat でインストール

  1. DaVinci Resolve を終了します。
  2. ダウンロードした MathMotionGraph.zip を右クリックし、「すべて展開」を選びます。
  3. 展開したフォルダ内の install.bat をダブルクリックします。
  4. Installation complete. と表示されたら、キーを押して画面を閉じます。
  5. 展開したフォルダ内の Fonts フォルダにある .otf を開き、「インストール」を選びます。
  6. DaVinci Resolve を起動します。

プラグインを確認する

  • Fusion で Shift + Space を押し、MathMotionGraph と検索します。MathMotionGraph ノードが追加されたら Fuse は正しくインストールされています。
  • エディットページでは「エフェクト」→「ジェネレーター」に MathMotionGraph が表示されるか確認します。
  • 使い方については MathMotionGraph の使い方 を参照してください。

手動インストール

install.bat で追加できない場合は、DaVinci Resolve を終了して以下のファイルをコピーします。パスをエクスプローラーのアドレスバーに貼り付けて開き、フォルダがなければ作成してください。Installation complete. の表示だけではコピーの成功を確認できない場合があります。

Fuse

展開した MathMotionGraph フォルダ内の Fuses フォルダにある MathMotionGraph.fuse を以下へコピーします。

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Edit

展開した MathMotionGraph フォルダ内の Edit フォルダにある MathMotionGraph.setting と MathMotionGraph.png を以下へコピーします。

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Generators

コピー後、DaVinci Resolve を再起動し、プラグインを確認してください。

うまくいかない場合

うまくいかない場合には、MathMotionGraph FAQを参照してください。
