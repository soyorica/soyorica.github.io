MathText FAQ

インストールについて

install.batを実行できません。

  • 様々な原因が考えられるため、確実な解決策を提示することができません。
  • そのような場合には、手動インストール の手順に従ってください。

インストールしてもプラグインが表示されません。

  • ZIP をすべて展開し、展開先の install.bat を実行したか確認してください。
  • DaVinci Resolve を再起動してください。
  • Fusion のノード検索で確認してください。Fusion では Shift + Space で MathText を検索します。
  • 見つからない場合は 手動インストール のコピー先に、対象ファイルがあるか確認してください。
  • エディットページの「タイトル」に MathText があるか確認してください。

Installation complete. と表示されたのに使えません。

  • install.bat だけを別のフォルダに移動せず、同梱ファイルと一緒に実行してください。
  • 以下のフォルダにMathText.fuseがあるかを確認し、なければ 手動インストール の手順に従ってコピーしてください。
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses
  • Fusion のノードがあるのにエディットページに表示されない場合は、Edit のコピー先 に MathText.setting と MathText.png があるかも確認してください。

Mac / Linux でも install.bat を使えますか？

  • install.bat は Windows 用です。このサイトのパスとインストール手順も Windows 向けです。
  • 手動インストール を参考に、類似するフォルダに各ファイルをコピーしてください。ただし、Windows以外での正常な動作は保証できません。

更新・アンインストールはどうしますか？

  • 更新前には、使用中のプロジェクトと旧バージョンのファイルをバックアップしてください。
  • 更新は DaVinci Resolve を終了し、新しい配布 ZIP を展開して install.bat を実行します。同名のファイルは上書きされます。
  • アンインストールする際には DaVinci Resolve を終了し、同封されたuninstall.batを実行してください。
  • uninstall.bat が正常に動作しない場合には、手動インストールに記載されたフォルダから MathText.fuse・MathText.setting・MathText.png のみを削除します。
  • ほかのプラグインのファイルや、Fusion フォルダ全体は削除しないでください。
  • プラグインを使用中のプロジェクトは、削除後に同じように表示できなくなる場合があります。

製品について

フォントは何をインストールすればいいですか？

  • MathText は数式用のフォントデータを内蔵しているため、フォントの追加インストールは不要です。

数式が表示されません。

  • Formula に x^2 を入力して確認してください。
  • $ などの囲みを付けず、数式本体を入力してください。
  • \frac{a}{b} などのコマンドの綴りと、{ } の対応を確認してください。
  • すべての LaTeX コマンドに対応しているわけではありません。入力例 から少しずつ式を追加してください。
  • サイズ、配置、色の透明度も確認してください。

ジェネレーターに MathText がありません。

  • MathText はエディットページの「タイトル」に表示されます。
  • 見つからない場合には、Shift + SpaceでMathTextと検索して、Enterを押してください。
