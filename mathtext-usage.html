MathText の使い方

LaTeX 形式の数式記法を使って、数式を映像内に表示するジェネレーターです。LaTeX のすべての機能に対応するものではありません。

基本的な使い方

  1. インストール でインストールします。MathText のフォントは内蔵されています。
  2. エディットページの「エフェクト」→「タイトル」から MathText を映像の上のトラックに配置します。
  3. インスペクタの Formula に数式を入力します。例：\frac{1}{2}。
  4. Size で大きさ、Position X / Position Y で配置を調整します。
  5. Appearance の Base Color で基本の色を調整します。
  6. Write Animation のWriteProgressを使用して、登場アニメーションを追加することができます。
  7. Fusion では Shift + Space で MathText を追加します。単独出力は MediaOut へ、映像に重ねる場合は Merge へ接続します。

数式の入力例

表現 Formula に入力する内容
上付き・下付き x^2 + a_1
分数 \frac{a+b}{c}
平方根 \sqrt{x}
積分 \int_a^b f(x)\,dx
ギリシャ文字 \alpha + \beta
文字に色を付ける y = a {\color{1}x} + b
  • 数式を $ で囲まず、数式本体を入力してください。
  • 複数の文字をまとめる場合は { } を使います。例：x^{a+b}。
  • 特定の文字の色を変える際には、\color{}を使用してください。{}内にはredなど色の名前のほか、インスペクタで指定した色として1～4を入力することができます。
  • 数式が表示されない場合は、括弧の対応やコマンドの綴りを確認し、短い式で試してください。また、画面に表示されるエラーメッセージを確認してください。

アニメーションの設定

設定 内容
Write 登場アニメーションの進行度
Erase 退場アニメーションの進行度
Charactor Lag 各文字のアニメーション開始時点をどの程度重ねるか
Outline width アニメーションの際の線の太さ。アニメーション終了後に表示される文字の線の太さには影響しない
