インストール 使い方 FAQ

MathText のインストール

Windows 向けのインストール手順です。

install.bat でインストール

  1. DaVinci Resolve を終了します。
  2. ダウンロードした MathText.zip を右クリックし、「すべて展開」を選びます。
  3. 展開したフォルダ内の install.bat をダブルクリックします。
  4. Installation complete. と表示されたら、キーを押して画面を閉じます。
  5. DaVinci Resolve を起動します。

プラグインを確認する

  • Fusion で Shift + Space を押し、MathText と検索します。MathText ノードが追加されたら Fuse は正しくインストールされています。
  • エディットページでは「エフェクト」→「タイトル」に MathText が表示されるか確認します。
  • 使い方については MathText の使い方 を参照してください。
  • MathText はフォント内蔵のため、追加インストールは不要です。

手動インストール

install.bat で追加できない場合は、DaVinci Resolve を終了して以下のファイルをコピーします。パスをエクスプローラーのアドレスバーに貼り付けて開き、フォルダがなければ作成してください。Installation complete. の表示だけではコピーの成功を確認できない場合があります。

Fuse

展開した MathText フォルダ内の Fuses フォルダにある MathText.fuse を以下へコピーします。

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses

Edit

展開した MathText フォルダ内の Edit フォルダにある MathText.setting と MathText.png を以下へコピーします。

%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles

コピー後、DaVinci Resolve を再起動し、プラグインを確認してください。

うまくいかない場合

うまくいかない場合には、MathText FAQを参照してください。
